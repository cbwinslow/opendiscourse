- (decision) Must-have core tracks: legislation+votes (1), bill/law text (2), outcomes by place (5), report cards/summary sheets (8)
- (decision) Very important, harder inference: donations/lobbying (3), federal awards/regulation beneficiaries (4), politician trades from STOCK Act disclosures (6)
- (decision) Track 7 statements vs votes is wanted and is the key differentiator; hard
- (decision) Outcomes scope: all of them (income, crime, standard of living, housing, immigration, taxes, health...) at district, county, state
- (decision) Audience: researchers plus ordinary readers; free and local; OpenStates/think-tank/NGO equivalent
- (assumption) Do not start over: identity, provenance, legislation, Epic 10 district slice are the foundation
- (assumption) Language rules: timelines and evidence not legal conclusions; consistency check not 'lie'; many explained metrics not one corruption score; misandry needs measurable definition
- (event) Operator picked option A: write vision brief before data audit; AGENTS.md rule changes only after operator sees brief
- (decision) First user is the operator as researcher; design so an organization (think tank) could run it; output is published findings (blog/Substack), not a voter-facing app
- (decision) Point-in-time report cards wanted: store every fact with an as-of (knowledge) date so a card can be regenerated for any past date; design now, build later
- (decision) Report card contents: party loyalty with dissent reasons where available, attendance, ideology position from voting history, donor breakdown and concentration, tenure and prior offices, district change since election, consistency over tenure (flip-flops), ethics actions, committee memberships, donor links to other candidates
- (decision) Statements sources: Congressional Record floor speeches first; GDELT news-quoted statements as lower-trust reported statements; social media later and only if legally and cheaply available
- (decision) Credibility rule: honest metrics; every metric labelled established/estimated/exploratory with method and inputs; deservedly right, not pretending
- (decision) Do not hand-label members as fascist/communist/etc.; use empirical measures (Voteview DW-NOMINATE already loaded) plus issue-level measures
- (direction) Operator stated strong prior views and wants report cards to 'prove' them; brief requires the tool to be able to contradict operator priors: hypotheses and metrics defined before results are viewed; null results published
- (direction) Operator limits: do not dox anyone, do not break laws
- (assumption) Donor 'country of origin' is mostly not in FEC data (foreign nationals barred); use employer, occupation, state, PAC type, concentration instead; foreign influence via FARA/LDA is a separate source
- (assumption) Illegal immigration per district is not directly measured; use CBP encounters, modelled unauthorized-population estimates (state level), foreign-born share (ACS), and sanctuary-policy lists with stated definitions
- (event) Operator approved brief; operator clarified they are nonpartisan, earlier rhetoric not a policy input; objectivity principle accepted; addendum with sources/metrics/methods written
- (decision) Add: LDA filings link bills to lobbyists; CES for district opinion; CAP topic codes for flip-flops; district change is context not credit; donor grouping is a separate labelled estimated layer
- (decision) Scope widened: any office-holder (senators, president, governors, state legislators via OpenStates #102), one person-office-term model; local officials need a source; courts out
